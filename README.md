# EduQuest — учись играя

Образовательная игровая платформа для школьников Узбекистана: дневник с расписанием на каждый день, уроки с AI-учителем Луми, мини-игры после каждой темы, итоговые контрольные, XP и уровни, валюта Lumos и магазин, достижения, глобальный рейтинг и тест «Кем стать?».

Стек: Next.js 16 (App Router, JavaScript), Tailwind CSS 4, Lucide React, Recharts, Supabase, Anthropic SDK (Claude).

## Быстрый старт

```bash
npm install
npm run dev          # http://localhost:3000
```

Без настроек приложение работает в **демо-режиме**: аккаунты и прогресс хранятся в `localStorage` этого браузера (пароль — только в виде хэша PBKDF2), в рейтинге только ты сам, а AI-учитель использует заранее подготовленные объяснения. Всё это явно обозначено в интерфейсе. Для быстрой проверки на главной есть кнопка «Попробовать как гость».

## Подключение Supabase и AI

1. Скопируйте `.env.example` в `.env.local` и заполните:

   | Переменная | Где взять | Где используется |
   |---|---|---|
   | `NEXT_PUBLIC_SUPABASE_URL` | Supabase → Project Settings → API | браузер + сервер |
   | `NEXT_PUBLIC_SUPABASE_ANON_KEY` | там же (anon / public) | браузер |
   | `SUPABASE_SERVICE_ROLE_KEY` | там же (service_role) | **только сервер** |
   | `ANTHROPIC_API_KEY` | console.anthropic.com | только сервер (`/api/tutor`) |

2. В Supabase → SQL Editor выполните `supabase/schema.sql`, затем `supabase/seed.sql` (каталог предметов, уроков, вопросов, достижений и товаров).
3. Перезапустите `npm run dev`. Баннер «Демо-режим» исчезнет, регистрация пойдёт через Supabase Auth.

Переменные можно задавать независимо: например, только `ANTHROPIC_API_KEY` включит живые ответы Луми в демо-режиме.

## Как устроено

**Игровой движок** — `lib/engine.js`. Чистые функции над состоянием ученика: `completeGame`, `submitExam`, `buyItem`, `equipItem`, `claimQuest`, `saveCareer`, `updateProfile`. Один и тот же код работает в браузере (демо) и на сервере (`/api/action`), поэтому правила начисления нигде не дублируются. Все награды проходят через один ключ награды (`lesson:<id>:pass`, `exam:<id>:pass`, `quest:<день>:<id>` …) — повторно получить ту же награду невозможно.

**Дневник** — `lib/schedule.js`, страница `/diary`. После входа ученик попадает в дневник: шестидневная учебная неделя, 4 урока в день со временем, оценки по пятибалльной шкале (6–7 верных → 5, 5 → 4, 4 → 3; неудачные попытки оценкой не считаются), ежедневные задания как «домашнее задание». Расписание не хранится, а вычисляется из даты, класса и прогресса **на начало дня** по ташкентскому времени. Поэтому оно само обновляется каждый день в 00:00: пройденный сегодня урок остаётся в сегодняшнем расписании с оценкой, а завтра его место занимает следующая тема. Воскресенье — выходной. Дни до регистрации пустые.

**Учебный контент** — `lib/content/lessons/*.js`. 7 предметов, 35 уроков, около 320 вопросов 7 форматов (выбор ответа, определение, формула, задание с картинкой, пропуск, пары, порядок шагов). У каждого урока есть пошаговое объяснение, упрощённая версия, примеры из жизни, проверочный вопрос, частые вопросы и интерактивная визуализация (`components/visuals`, 31 компонент). Новый предмет — это новый файл в `lessons/`, подключённый в `lib/content/index.js`. Каталог (`lib/content/subjects.js`) содержит 20 предметов 1–11 классов с учётом класса ученика; для предметов без готовых уроков честно показан план тем «в разработке».

**Экономика** — `lib/economy.js`, `lib/levels.js`. XP отвечает за уровень и рейтинг. Lumos — валюта магазина, в рейтинг не входит, а в магазине нет товаров, дающих XP.

**Картинки** — эмодзи заменены 3D-иллюстрациями [Microsoft Fluent Emoji](https://github.com/microsoft/fluentui-emoji) (лицензия MIT), файлы лежат локально в `public/emoji/`. Компоненты `Emoji`/`Em` (`components/ui/Emoji.js`) подставляют картинку вместо символа.

## Безопасность (режим Supabase)

- RLS включён на всех таблицах. Ученик может только **читать** свои строки; политик на запись нет, поэтому изменить XP, Lumos или результаты с клиента нельзя.
- Все изменения идут через `/api/action`: сервер проверяет JWT, сам загружает состояние, **повторно проверяет ответы** по контенту, проверяет, что набор вопросов принадлежит уроку, и только потом записывает изменения ключом `service_role`.
- Таблица `reward_claims` с первичным ключом `(user_id, key)` не даёт начислить награду дважды. Колонка `profiles.version` защищает от гонок при параллельных запросах.
- Рейтинг отдаётся функцией `get_leaderboard`, которая возвращает только публичные поля учеников, разрешивших показ (с учётом «скрыть настоящее имя»).
- Ключи `SUPABASE_SERVICE_ROLE_KEY` и `ANTHROPIC_API_KEY` не имеют префикса `NEXT_PUBLIC_` и в браузер не попадают.

## Известные ограничения

- **Режим Supabase не проверен на реальном проекте**: схема, политики и серверные маршруты написаны, но в этой среде не было базы Supabase. Демо-режим проверен в браузере от начала до конца.
- Правильные ответы входят в клиентский бандл (нужны для мгновенной обратной связи). Сервер перепроверяет ответы, но технически подготовленный ученик может подсмотреть их в коде. Для полной защиты вопросы нужно отдавать с сервера без ответов.
- Интерактивные уроки есть по 7 предметам (математика, химия, физика, биология, история Узбекистана, английский, информатика). Остальные предметы каталога пока только с планом тем.
- Рейтинг друзей, узбекский и английский интерфейс заложены в архитектуру, но ещё не реализованы.
- Кнопка «Задать вопрос» убрана. С `ANTHROPIC_API_KEY` у кнопок «Объясни проще» и «Покажи пример» появляется ссылка «Попросить у AI другой вариант»; без ключа используются только подготовленные объяснения.
